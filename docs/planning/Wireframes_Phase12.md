
# Phase 12: Wireframes (Low-Fidelity Structure)
## Aurelle — Premium Dating Ecosystem

Low-fidelity wireframes define **layout and hierarchy only** — no color/type yet (that's applied in Phase 13 High-Fidelity UI). Documented here as structured screen specs since static wireframe images aren't the efficient medium for this deliverable; Phase 13 will render actual high-fidelity mockups.

---

### Screen 1: Onboarding — Verification Gate
```
[ Progress indicator: Step 3 of 5 ]
[ Headline: "Let's verify it's really you" ]
[ Subtext: explains why — trust/safety, one-time step ]
[ Card: "Scan Government ID" — tap to launch camera flow ]
[ Card: "Take a Liveness Selfie" — tap to launch camera flow ]
[ Footer: link to "Why we verify" (privacy education, builds trust rather than friction resentment) ]
[ Primary CTA: disabled until both steps complete ]
```
**Design intent:** Turn the highest-friction step into a trust-building moment, not a compliance checkbox — copy and pacing matter as much as layout here.

### Screen 2: Home — Today's Curated Matches
```
[ Top bar: Aurelle wordmark | Advice/Dating segmented control | Profile icon ]
[ "Today's Matches" headline + count (e.g., "3 curated for you") ]
[ Match card (large, one at a time — NOT a swipe deck): 
    photo, name, age, verified badge, top 2 compatibility highlights, 
    "View full profile" / "Say hello" CTAs ]
[ Secondary: small list of previous days' matches (collapsed) ]
```
**Design intent:** Deliberately NOT an infinite swipe stack — reinforces "curated, not endless" brand promise architecturally, not just in marketing copy.

### Screen 3: Chat / Conversation
```
[ Header: match name, verified badge, safety-center icon (always visible) ]
[ Message thread: bubbles, voice note waveform previews, photo thumbnails ]
[ Inline AI safety banner (contextual, only appears if risk detected — e.g., "This message mentions sending money — be cautious") ]
[ Composer: text input, voice note button, photo attach, icebreaker suggestion chip ]
```
**Design intent:** Safety banner is contextual/rare, not a persistent nag — preserves premium feel while still delivering the safety promise when it matters.

### Screen 4: Advice — Discover
```
[ Segmented filter: audience (Men/Women/LGBTQ+/Life-stage) ]
[ Featured article/topic cards ]
[ "Ask the AI Coach" persistent entry point (not buried) ]
[ Saved/library shortcut ]
```

### Screen 5: Safety Center (reachable in ≤2 taps from anywhere in Dating tab)
```
[ Panic button (prominent, top) ]
[ Report a user / Block a user ]
[ Share my date details with emergency contact ]
[ Privacy & visibility quick controls ]
[ Link to full safety resources ]
```
